# ML1509 Deep RL Laboratory

All 11 lab experiments in standalone Python and MATLAB files, ready to run without comments.

## 🚀 One-Line Download Command (No Git Required)

Run this single command in the Ubuntu terminal to instantly download all experiment files into your current folder:

```bash
curl -sL https://github.com/prakash-2409/Deep-RL-lab/archive/refs/heads/main.tar.gz | tar -xz --strip-components=1
```

Or using the download script:

```bash
curl -sSL https://raw.githubusercontent.com/prakash-2409/Deep-RL-lab/main/download.sh | bash
```

Or download any specific experiment file directly:

```bash
curl -sLO https://raw.githubusercontent.com/prakash-2409/Deep-RL-lab/main/ex1.py
```
